# Windows での始め方（コマンド入力なし）

黒い画面にコマンドを打つ必要はありません。**ファイルをダブルクリックするだけ**です。

---

## 準備：フォルダを解凍する

`partspost_kit.zip` を右クリック →「すべて展開」を選び、デスクトップなど分かりやすい場所に展開します。

> **重要：** zipの中身を見ているだけでは動きません。かならず「すべて展開」してください。

展開すると `partspost` フォルダの中に、こういうファイルが並びます。

```
Demo.bat          ← まずこれでお試し（ID不要）
1_Setup.bat       ← Client IDを登録
2_MakePage.bat    ← 実データでページを作る
partspost.html    ← 生成された完成ページ
（その他はプログラム本体）
```

> ファイル名は英語ですが、**実行すると日本語の案内が表示されます。**
> 以前のバージョンで文字化けしていた問題を解消するため、
> バッチファイル自体からは日本語を取り除いてあります。

---

## ステップ0：まず動くか確かめる（任意・1分）

`Demo.bat` をダブルクリックしてください。
ブラウザが開いてサンプルのページが表示されれば、環境は問題ありません。

**Pythonが入っていない場合**は、その旨のメッセージが出ます。
Microsoft Store を開いて「Python」を検索し、`Python 3.12` などをインストールしてください（無料・数分）。
インストール後、もう一度ダブルクリックすれば動きます。

---

## ステップ1：Client IDを登録する

`1_Setup.bat` をダブルクリックします。

黒い画面が開いて、こう表示されます。

```
 Yahoo!で発行した Client ID を貼り付けてください。
 （右クリックで貼り付けできます。貼り付けたらEnterキー）

 Client ID > _
```

ここで **Client IDを貼り付けて、Enterキーを押します。**

> **貼り付け方：** `Ctrl+V` が効かない場合があります。その時は**マウスの右クリック**を1回してください。それだけで貼り付けられます。

Enterを押すと、自動で保存＋接続テストまで実行されます。

**成功するとこう出ます：**

```
 ✓ 成功！ 全1,243件ヒット（うち先頭5件を表示）

   1. ¥   780  送料無料  タミヤ 15435 大径ローハイトタイヤ...
```

**失敗した場合**もエラーの原因が表示されます。よくあるのは次の2つです。

- **HTTP 403** … 登録直後の反映待ちです。5分ほど待って再実行してください
- **文字数が異常** … 貼り付けが途中で切れています。もう一度コピーし直してください

---

## ステップ2：実データでページを作る

`2_MakePage.bat` をダブルクリックします。

```
 検索したい言葉を入力してください。
 （そのままEnterを押すと「ミニ四駆 大径ローハイトタイヤ」で検索します）

 検索語 > _
```

そのまま **Enterを押すだけ** でOKです。別の言葉で試したい時はここに入力します。

生成が終わると**自動でブラウザが開き**、実在庫の入ったページが表示されます。

---

## 困ったときは

**ウィンドウが一瞬で消える**
→ エラーが出ています。`1_Setup.bat` から実行し直すと、メッセージが残るようになっています。

**「Pythonが見つかりません」と出る**
→ Microsoft Store から Python をインストールしてください。インストール時の追加設定は不要です。

**文字化けする**
→ このバージョンでは解消済みです。それでも化ける場合はお知らせください。

**`2_MakePage.bat` で「設定がまだです」と出る**
→ 先に `1_Setup.bat` を実行してください。

**0件しか取れない**
→ 検索語を変えてみてください。「ミニ四駆 タイヤ」など短めの言葉のほうがヒットします。
