# Switch Oni キャラクター設定(開発発信サイト用・改訂版)

## ブランド上の位置づけ

「Switch On」は当社のスローガンです。これを体現するキャラクターが2系統あります。

| キャラクター | 役割 | 備考 |
|---|---|---|
| スイッチオンマン | 社外に向けた「営業の顔」 | 営業部・矢部さん(実在する社員) |
| Switch Oni | 開発の現場で情熱を灯す「開発の顔」 | 本ドキュメントの対象 |

両者は同じスローガンを共有する仲間として扱います。スイッチオンマンの応援を受けながら、少しずつ認知を広げていく流れです。

## コンセプト

面倒、焦り、落ち込みといった日常の気持ち(**青**)を、スイッチひとつでポジティブな情熱(**赤**)に切り替えます。

## キャラクター

### 赤怒(せきど)/ SEKIDO

- **立場**: Switch Oniのボス
- **外見**: 赤い肌、1本角、白の三つ揃い
- **性格**: 声が大きく、喜怒哀楽のすべてが全力。怒りっぽく見えるが、その怒りは「もっと面白くできるはず」という情熱の裏返し
- **癖**: 褒められると照れる。仲間の成長には号泣する
- **決めポーズ**: スイッチを入れる合図の**L字サイン**

### 青鬼衆(あおきしゅう)/ AOKISHU

- **立場**: 赤怒を支える、たくさんの部下。3種類の個体が入れ代わり立ち代わり、どこにでも現れる
- **性格**: 真面目で心配性。冷や汗をかきながらも、荷物運び、書類整理、電話、PC作業まで、開発の日常を黙々と支える
- **スイッチ**: 赤怒のL字サインを受けると、一斉にスイッチが入る
- **個体名**: なし。「数と連携で見せる」キャラクター
- **バリエーション**: がっしり・大柄・細身の3種類。素材を使い回すときのバリエーションとして扱う

## ビジュアル資料(メインビジュアルより)

赤怒を中央に大きく配置し、左右に青鬼衆を並べた構図です。背景は灰色のコンクリート壁で、赤い筆文字の「Switch Oni」ロゴが入ります。

| 要素 | 赤怒 | 青鬼衆 |
|---|---|---|
| 肌 | 赤 | 青 |
| 角 | 1本 | 2本(画像上) |
| 目 | 黄色 | 黄色 |
| 牙 | あり | あり |
| スーツ | 白の三つ揃い(ジャケット・ベスト・パンツ) | 黒のスーツ |
| シャツ・ネクタイ | 黒シャツ、赤ネクタイ、赤ポケットチーフ | 黒シャツ、紺ネクタイ |
| ポーズ | L字サイン(人差し指を立て、親指を横に開く) | 一部の個体が同じL字サインを返す |

### 設定と画像の差異(要判断)

- 青鬼衆の角は、設定文に記載がなく、画像では2本です。赤怒の「1本角」と差別化する意図なら、設定に明記しておくと素材を使い回しやすくなります。
- 設定文の「冷や汗をかく」は、画像では表現されていません。表情は無表情〜厳めしい顔です。
- 画像では、青鬼衆の体格差(がっしり・大柄・細身)は、はっきり描き分けられていません。
